Apple A20 (TSMC 2nm) — Wafer IN에서 출하까지, 식각 중심 정리

반도체 식각 논문 스터디 · 조사 기준일 2026-10-05 · 리서치: gpt-6-astra (high, 웹 검색) · 판단 자문: jev · 정리: Claude

← 목차 · 주요 용어집 · 식각 지식 그래프 열기

읽기 전에. TSMC는 N2 공정 레시피를 공개하지 않는다. 아래 공정 순서와 식각 과제는 공개된 일반 GAA 나노시트 공정 흐름을 N2/A20에 적용해 재구성한 것이다. 각 항목에 확인 수준을 표시했다: 확인 제조사 공식 자료 추정 일반 공정 기반 재구성 루머 공급망·분석가 주장 미공개 검증 가능한 수치 없음

1. 한눈에 보기

GAA 나노시트TSMC 첫 GAA 노드 (N2) 확인
2025년 4분기N2 양산 개시 확인
Fab 20 · Fab 22신주 Baoshan · 가오슝 Nanzi 확인
2026-09-09A20 Pro 발표 (iPhone 18 Pro/Pro Max) 확인

A20이 무엇인가. Apple의 SoC 이름이다. TSMC 노드 이름(N2, N2P, A16, A14)과는 별개다. Apple은 A20 Pro가 "최신 2nm 공정"으로 만들어지고, 로직 다이와 메모리를 옆으로 나란히 놓는 새 패키징을 쓴다고 공식 발표했다 확인. 정확히 N2인지 N2P인지는 Apple이 밝히지 않았다 업계 추정: N2.

식각 관점의 핵심. FinFET에서 GAA로 넘어오며 새로 생긴 가장 어려운 식각은 세 가지다. ① 내부 스페이서를 위한 SiGe 측면 부분 리세스, ② 채널을 띄우는 SiGe 희생층 완전 제거(채널 릴리스), ③ 좁은 시트 사이의 게이트 금속 선택 제거. 셋 모두 "Si는 거의 건드리지 않고 SiGe나 금속만 옆 방향으로 정밀하게 걷어내는" 등방성·고선택비 식각이다.

2. 전체 흐름 지도 — 식각이 들어가는 곳

전공정 · FEOL (트랜지스터)
웨이퍼 입고·세정→ 웰 형성→ Si/SiGe 초격자 에피→ 스택 패터닝 · STI→ 더미 게이트 · 스페이서→ S/D 리세스→ SiGe 측면 리세스 · 내부 스페이서→ S/D 에피→ 더미 게이트 제거→ 채널 릴리스→ HKMG 대체 게이트
전공정 · MOL / BEOL (배선)
자기정렬 컨택→ BEOL 비아·트렌치 (low-k)→ SHPMIM · 패드 개구→ WAT · CP 테스트→ Wafer OUT
후공정 (조립·테스트)
범핑 · RDL 시드 제거→ 박막화 · 다이싱→ 패키징 (로직+메모리 병렬)→ 최종 테스트 · 출하
식각이 핵심인 단계 GAA에서 새로 생긴 고난도 식각 식각이 주가 아닌 단계

순서는 일반 GAA 통합 흐름 기준 추정. 특히 웰·STI·에피의 순서는 통합 방식에 따라 달라진다.

3. GAA의 핵심 식각 3장면

Si (채널이 됨) SiGe (희생층, 제거됨) 내부 스페이서 외부 스페이서 S/D 에피 식각으로 제거되는 부분

게이트 방향 단면의 개념도. 시트 수·두께는 예시이며 A20의 실제 치수는 미공개.

4. 전공정 식각 단계별 상세

★ = FinFET 대비 GAA에서 새로 생겼거나 훨씬 어려워진 식각

E1

웨이퍼 세정 · 전처리

추정
무엇을
자연산화막·오염물 제거, 에피 성장에 맞는 표면 준비
식각 종류
습식 세정, 건식 전처리 (산화막 제거)
핵심 과제
산화막은 지우되 Si 손실·표면 거칠기는 최소화. 과하면 이후 Si/SiGe 계면 품질이 나빠짐
E2

나노시트 스택 패터닝 · STI 리세스

추정
무엇을
Si/SiGe 교대 적층막을 좁고 긴 기둥(스택)으로 깎고, 사이를 절연막으로 채운 뒤 절연막을 다시 낮춤
식각 종류
EUV/DUV 패턴 → 하드마스크 → ICP/RIE 이방성 식각, 이후 산화막 리세스
핵심 과제
Si와 SiGe를 한 번에 수직으로 관통 (두 재료의 식각 속도가 달라 노칭·테이퍼 위험), 폭 편차·측벽 거칠기, 패턴 밀도에 따른 로딩 효과. STI 리세스 때 스택 보호
영향
스택 폭 = 채널 폭. 편차가 그대로 트랜지스터 특성 산포가 됨
E3

더미 게이트 · 외부 스페이서 식각

추정
무엇을
희생 폴리 게이트를 패터닝하고, 측벽에 스페이서만 남김
식각 종류
이방성 플라즈마 식각, 스페이서 에치백
핵심 과제
게이트 CD·수직 프로파일, 스페이서 두께 균일성. 스택 3차원 구조의 측벽에 스페이서 잔류물이 남지 않게 (FinFET보다 높은 종횡비)
E4

S/D 리세스

추정
무엇을
게이트 양옆 스택을 깎아 소스·드레인이 들어갈 자리를 만듦 (위 그림 ①)
식각 종류
이방성 플라즈마 식각
핵심 과제
모든 시트의 끝단이 깨끗하게 드러나도록 깊이·측벽 각도 제어. 스페이서 아래로 파고들지 않게
E5 ★

SiGe 측면 리세스 · 내부 스페이서 에치백

추정최고 난도
무엇을
드러난 SiGe 층의 끝만 옆 방향으로 몇 nm 파낸 뒤 절연막을 채우고, 바깥쪽 잉여 절연막을 걷어냄 (위 그림 ②)
식각 종류
SiGe : Si 고선택비 등방성 식각 (건식/기상), 이후 절연막 에치백
핵심 과제
위아래 모든 시트에서 같은 깊이로 리세스. Si는 거의 손상 없이. 리세스 끝 모양(평평 vs 둥근 형태). 에치백 때 Si·SiGe·외부 스페이서와의 선택비
영향
덜 파면 게이트–S/D 기생 커패시턴스↑, 너무 파면 실효 게이트 길이·접합 특성이 무너짐
E6

S/D 에피 전처리

추정
무엇을
에피 직전 채널 끝단의 자연산화막 제거
식각 종류
건식 전처리 (저손상)
핵심 과제
얇은 채널 끝과 방금 만든 내부 스페이서를 보존. 표면 손상은 에피 결함·높은 접촉 저항으로 이어짐
E7

더미 게이트 제거

추정
무엇을
ILD 충진·CMP 후 폴리 더미 게이트와 희생 산화막을 걷어내 게이트 자리를 엶
식각 종류
선택적 습식/건식 Si 제거
핵심 과제
더미 게이트도 Si, 채널도 Si. 보호막이 언제 어디를 덮고 있는지(노출 순서)가 채널 보호를 결정
E8 ★

채널 릴리스 — SiGe 희생층 완전 제거

추정최고 난도
무엇을
게이트 영역의 SiGe를 전부 제거해 Si 나노시트를 공중에 띄움 (위 그림 ③)
식각 종류
고선택비 등방성 건식·기상 식각 또는 습식
핵심 과제
동시에 지켜야 할 것: Si 손실·거칠기 최소, Ge 잔류 없음, 내부 스페이서 침식 없음, S/D 손상 없음, 시트끼리 달라붙지 않음(습식 건조 시 표면장력 문제)
공개 정도
TSMC의 가스·온도·압력·선택비·종말점 검출 방식 미공개
E9 ★

HKMG — 게이트 금속 선택 제거 · 리세스

추정
무엇을
ALD로 시트 둘레에 high-k·일함수 금속을 입힌 뒤, nFET/pFET 별로 일부 금속을 선택 제거하고, 게이트 금속 리세스·캡 형성
식각 종류
금속 선택 습식/건식 식각, 금속 리세스. 원자층 수준 제어가 필요한 곳은 ALE 후보
핵심 과제
시트 사이 수 nm 틈에서 금속만 균일하게 제거하고 high-k·채널 계면은 보존. 잔사·두께 편차 → 문턱전압 산포·누설

ALE(원자층 식각): 표면 개질과 제거를 분리해 한 층씩 깎는 기술. 정밀 식각의 후보이지만 N2의 모든 식각에 ALE가 쓰인다고 단정할 수는 없다.

E10

MOL — 자기정렬 컨택(SAC) 식각

추정
무엇을
게이트·S/D까지 좁은 컨택 홀을 뚫음
식각 종류
고종횡비 유전체 식각, 게이트 캡 대비 고선택비
핵심 과제
홀은 끝까지 열되 게이트 캡·스페이서는 뚫지 않기(뚫리면 게이트–컨택 단락). 바닥 잔사, S/D 손상
공개 정도
컨택 금속(W·Co·Ru 등) 구성 미공개
E11

BEOL — 비아·트렌치 식각 (Cu 다마신, low-k)

추정
무엇을
low-k 절연막에 배선·비아 모양을 식각하고 Cu를 채운 뒤 CMP. 층마다 반복
식각 종류
유전체 플라즈마 식각 (EUV/DUV 패턴)
핵심 과제
low-k 플라즈마 손상(탄소 손실·흡습 → 유전율 상승), 비아 바닥 완전 개방, 하부 금속 손상 방지, 비아–배선 정렬
주의
Cu 다마신은 Cu를 직접 깎지 않고 절연막을 깎아 Cu를 채운다. Ru 직접 식각(semi-damascene)은 imec 연구 단계로, N2 양산 채택 근거 없음 미공개. EUV 사용 확인, 층수 미공개
E12

SHPMIM · 패시베이션 · 패드 개구

기술 존재 확인순서 추정
무엇을
배선 스택 안에 고성능 MIM 커패시터(전원 안정용)를 만들고, 최상단 보호막을 덮은 뒤 패드만 엶
식각 종류
금속·유전체 식각, 패드 개구 식각
핵심 과제
MIM 가장자리 누설·단락, 얇은 절연막 손상, 패드 잔사·과식각

5. 웨이퍼 테스트와 수율 — 식각 결함이 드러나는 곳

검사무엇을 보나식각 결함과의 연결
WAT / PCM테스트 구조의 문턱전압·누설·저항·정전용량채널 손실(E8), 컨택 잔사(E10), 비아 미개방·low-k 손상(E11)이 전기 이상으로 나타남
CP (Wafer sort)제품 다이별 기능·성능 등급, 양품 맵식각을 하는 단계는 아니며, 결함을 걸러냄
  • TSMC IEDM 2024: 256Mb SRAM 시험 칩 수율 약 90% 이상, 1,000시간 HTOL 통과 확인 — 시험 구조 수치이며 A20 제품 수율이 아님
  • 2025년 연차보고서: N2 "양호한 수율" (정성적) 확인
  • A20 다이 수율·패키징 수율 미공개

패키징 — 로직과 메모리를 나란히

구조 확인WMCM 명칭 루머
확인
Apple: "실리콘 다이와 메모리를 옆으로 나란히 배치해 메모리를 열 경로에서 빼고, 칩이 차세대 vapor chamber에 직접 붙게 함" (기존 InFO-PoP는 DRAM을 위에 쌓음)
루머
공급망 분석가: InFO → WMCM(Wafer-level Multi-Chip Module) 전환, MUF(몰디드 언더필) 사용 주장. TSMC/Apple 공식 명칭은 아님
식각 관여
접속면 세정, RDL 시드 제거, 비아 개구·잔사 제거. Chip-first / RDL-first 중 어떤 방식인지 미공개
