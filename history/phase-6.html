PSPI Etch BDI VV, LB Al RDL, Cu RDL eSD / eSiGe 위 용어들에 대한 설명

과정

  1. 20:04 astra(high, 웹 검색)에 리서치 요청을 백그라운드로 보냄: 가능한 해석을 모두 나열하고 가장 유력한 해석을 근거와 함께, 식각 포인트, 확실도 표시.
  2. 20:04 jev 자문 (기다리는 동안): 기록 위치 → 새 6단계 "용어·개념 학습" (0.58, 5단계 0.42로 신뢰도 낮음 — "새 성격의 작업은 새 단계" 규칙과 맞아 채택), 용어집·지식 그래프 추가 제안 → 0.76 (제안하기).
  3. 20:08 astra 완료 (약 4분 30초, 웹 검색 46회, 출처 23개). 원본은 로컬에만 보관.
  4. 20:09 가장 불확실한 VV/LB 해석을 Claude가 원문 특허(US9947645B2)에서 직접 확인: "via pad level → 'VV' level, pad level → 'LB' level", 그 위 폴리이미드 보호막은 "PV" level. 글자별 풀네임은 특허에도 없음.

#24

BDI 3D 페이지

2026-10-06 20:25

지시 (원문)

BDI도 3D 페이지로 추가해줘.

분석 (Claude의 정리)

  • #22에서 설명한 BDI(하부 유전체 절연)를 내부 스페이서·채널 릴리스에 이은 세 번째 3D 페이지로 만든다.
  • BDI는 공정 설명만으로는 "왜 필요한지"가 잘 안 보이므로, BDI가 없을 때의 누설 경로를 같은 3D에서 비교할 수 있게 한다.
  • N2의 BDI 채택 여부는 확인되지 않았으므로 공개 연구 기반 개념도임을 명시한다.

과정

  1. 20:26 jev 자문: "BDI 없이 보기" 비교 토글 → 0.72 (포함), 실패 실험 → 잔류·선택비·기공 세 가지 (1.00, 스택 처짐 추가는 0.00). 그대로 반영.
  2. 20:27 viz/bdi_3d.html 작성: 6단계(출발 → 고-Ge SiGe 선택 제거 → 절연막 채움 → S/D 리세스가 BDI에서 멈춤 → 내부 스페이서·에피 → 채널 릴리스·HKMG), 두 방향 단면, BDI 없이 보기(기생 채널·기판 누설 경로를 빨강으로), 실패 실험 3가지, "왜 필요한가"·"왜 어려운가".
  3. 20:30 첫 렌더링 확인 → 문제 3가지: BDI 없음 모드에서 S/D가 기판을 파고드는 모양이 겹쳐 보임, 빨간 누설 경로가 불투명한 기판 속에 묻혀 안 보임, 잔류 고-Ge와 BDI 절연막 면이 겹쳐 깜빡임. → S/D를 기판 표면 위에 놓고, 누설 경로는 항상 위에 그려지게, 잔류·기공은 단면보다 살짝 앞에 그리도록 수정.
  4. 20:32 게이트 아래 제거 진행은 채널 방향 단면에서만 보여 단계 설명에 안내 추가. 다른 3D 페이지와 목차에 링크 추가.

결과 / 증거

성공 BDI 3D 페이지 완성. 3D 연작 3편(내부 스페이서 · 채널 릴리스 · BDI)이 서로 링크됨.
