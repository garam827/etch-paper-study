  • 이 규칙을 CLAUDE.md에 정리해 매 세션 자동 적용되게 한다.
  • IP 주소·토큰 등 민감정보는 기록에 절대 남기지 않는다 (필요 시 마스킹).

  2. 18:28 astra / jev 확인 — 로컬 에이전트 정의(.claude/agents)와 실행 중인 다른 세션을 조회했으나 해당 이름의 자문자를 찾지 못함. 사용자 확인 필요
  3. 18:28 CLAUDE.md 작성 — 기록 규칙, 스크린샷 규칙, 민감정보 금지, astra/jev 자문 규칙 명시.
