#25

DPT · QPT 조사 시작

2026-10-07 20:26

지시 (원문)

DPT, QPT 에 대해 조사. 등장 배경과 최근 기술 동향 및 관련된 모든 난제들 포함.

분석 (Claude의 정리)

  • DPT(이중 패터닝)·QPT(4중 패터닝)는 ArF 이머전의 해상도 한계를 넘기 위한 멀티패터닝 기술. LELE 계열(나눠 노광)과 SADP·SAQP 계열(스페이서 복제)을 모두 다룬다.
  • 세 축: ① 등장 배경(Rayleigh 한계, EUV 지연, 노드·업체별 도입), ② 최근 동향(2023–2026: EUV 공존, High-NA, SMIC, DRAM, 장비), ③ "모든 난제" — 리소·식각·설계·계측·비용을 빠짐없이.
  • A20과 무관한 일반 패터닝 리서치이므로 기록 단계를 새로 만들지 jev에게 묻는다. 결과물은 식각 관점을 강조한 출처 달린 보고서.

과정

  1. 20:26 astra 리서치(gpt-6-astra high, 웹 검색)를 백그라운드로 시작. 요청: 배경·방식 분류·난제 전 범위·2023–2026 동향·핵심 논문, 식각 관점 강조.
  2. 20:27 jev 자문 3건: 기록 위치 → 새 7단계 "패터닝 기술 리서치" (선택 b, 확률 0.88, 신뢰도 0.82) · 결과물 형식 → 출처 달린 HTML 보고서 + 공정 단면 SVG (a, 0.94, 신뢰도 0.91) · 용어를 지식 그래프에 바로 추가할지 → 0.29 (이번엔 보류). 모두 그대로 반영.
  3. 20:30 astra를 기다리는 동안 공정 단면 SVG 생성 스크립트 작성: LELE, SADP, SAQP, 피치 워킹, 컷 마스크 평면도 5종. 첫 시도 코드가 꼬여서 한 번 다시 썼다.
  4. 20:35 기록 7단계 페이지(history/phase-7.html)를 만들고 1–6단계 페이지의 단계 이동 줄에 추가. 보고서 틀(스타일·목차·확인 수준 태그) 작성.
  5. 20:40 astra가 아직 검색 중이라 중간 보고 후 대기.

결과 / 증거

진행 중 리서치가 길어져 이 시점엔 보고서 미완성. 마무리는 #26.

2026-10-07 21:38

지시 (원문)

좋아, 결과 나오면 마무리까지 진행해줘

분석 (Claude의 정리)

  • #25의 남은 일 전부: astra 결과로 본문 작성 → 불확실한 주장 원문 대조 → 목차 추가 → 기록·스크린샷 → 보안 점검 → 커밋·푸시 → 사이트 확인.

과정

  1. 21:38 astra가 여전히 검색 중(시작 후 약 70분). 완료 대기를 걸어 둠.
  2. 21:47 astra 완료 (약 81분). 결과 530줄, 출처 71개. 원본은 research/dpt_qpt_raw.md에 로컬 보관(비공개). astra가 지시·요청의 표현 세 가지를 바로잡음: "~38–40 nm"는 pitch가 아니라 half-pitch(pitch는 76–80 nm), "SAPD"는 SADP, QPT는 네 번 노광이 아님(한 번 노광 + 스페이서 두 번).
  3. 21:49 가장 최신이라 불확실한 주장 두 개를 원문에서 직접 확인: Intel·ASML High-NA 발표(2026-09-07, Panther Lake 일부 제품의 선택된 레이어 양산 사용, "100만 장"은 인증·R&D·양산 합계) · TechInsights Kirin 9030 Pro 분석(2026-08-27, SMIC N+3는 7 nm급의 축소 발전, 상용 5 nm보다 상당히 덜 축소). 둘 다 astra 설명과 일치.
  4. 21:50 research/dpt_qpt_report.html 작성: 한눈에 보기 → 등장 배경(Rayleigh 표) → 도입 연표(2007–2026) → 방식 분류(LELE·LFLE·LE3·SADP·SAQP·SAOP·SALELE·컷/블록, SID/SIM) → 공정 단면도 → 난제 15가지(치수·위치 / 스페이서·맨드릴 식각 / 컷·블록 / 설계·계측·수율·비용) → 2023–2026 동향 8가지 → 논문 읽기 질문 7개 → 출처 71개.
  5. 21:52 로컬 미리보기에서 문제 3가지 발견·수정: LELE 그림 오른쪽 끝에 잘린 조각 → 어긋남 크기 조정 · 피치 워킹 그림에 "›" 화살표가 붙어 세 경우가 순서처럼 보임 → 화살표 제거 · 컷 그림 설명문이 잘림 → 본문과 겹치는 둘째 문장 삭제. 피치 워킹 수치(코어 14·갭 26, 선폭 24·갭 12)는 모델 P₀ = C + G + 2t로 검산.
  6. 21:59 증거 스크린샷 4장 저장. 목차(index.html) 맨 위에 보고서 추가, 기록 갱신.
